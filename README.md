# Learning C – My Practice Repository

This repo is where I collect all my beginner-friendly C programs.  
I'm learning step by step – from printing text to playing with memory and arrays.

Each folder shows one topic I practiced – nothing fancy, just learning by coding. 😊

## 📂 Topics I covered so far

| Folder | What’s inside |
|--------|------------------------------|
| `01_program_organization` | Basics of organizing code into files and functions |
| `02_memory_management` | Playing with pointers and dynamic memory (`malloc`, `free`) |
| `03_dynamic_array_linear` | Making an array that can grow bigger at runtime |
| `04_dynamic_array_linear_change` | Changing the size of the array with `realloc` |
| `05_input_formatting` | Reading input nicely with `scanf`, formatting output |
| `06_string_handling` | First and last names, string lengths, etc. |
| `07_string_length` | More practice with `strlen()` and string logic |
| `08_palindrome_check` | A tiny program that checks if a word is a palindrome |
| `09_dynamic_array_2D` | Trying 2D arrays using dynamic memory |
| `10_custom_types` | Structs, typedefs and simple custom types |
| `11_bit_operations` | Playing with bits and bitwise logic (AND, OR, shifts) |
| `12_matlab_bridge` | A small experiment mixing C with MATLAB (not required to run)

## 💬 Notes

- This is not a "real project" – just a learning repo 💡
- Code is kept simple and well-commented so I can come back and understand it later

I wanted a place to track my learning and share some beginner code.
